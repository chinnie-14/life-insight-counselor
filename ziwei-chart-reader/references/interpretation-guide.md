# Interpretation Guide

Use this file after generating a chart summary.

## Core Palace Priorities

For career:

- `命宫`: how the person acts, pushes, breaks, adapts
- `官禄`: role, career style, advancement pattern, work burden
- `迁移`: external environment, platform fit, change through movement
- `财帛`: how money is actually earned, controlled, or accumulated
- `福德`: internal reserves, fatigue, existential friction, recovery

For relationships:

- `命宫`
- `夫妻`
- `福德`
- `迁移`

For wealth:

- `财帛`
- `官禄`
- `田宅`
- `福德`

## How To Read Career Questions

When the user asks whether a year is stable or restructuring:

- read natal `命宫` for basic life mechanism
- read natal `官禄` for career mechanism
- read natal `迁移` for whether external change activates the person
- read yearly `官禄` and `迁移` mapping when available
- read `财帛` to check whether money follows position, mobility, or opportunism

## Useful Translation Style

Avoid just naming stars. Translate them.

Bad:

- `官禄宫武曲贪狼，所以事业很好。`

Better:

- `官禄宫这组更像“在复杂资源和变化局面里拿结果”的事业结构，所以你的职业推进不太像守在原位置慢慢熬出来，更像在新方向和重组里争到更高杠杆。`

## Boundaries

- One palace is never the whole story
- Do not pretend yearly movement overrides real life constraints
- If palace structure and lived reality diverge, say so
- Use chart support as structured evidence, not cosmic certainty
