# Degradation Rules

Use this file when the user's information is incomplete, contradictory, or too thin for a confident integrated reading.

## Goal

The purpose of degradation is not to refuse help. It is to reduce overclaiming while still giving the user something useful.

## General Rule

When data quality drops, move:

- from prediction to scenario guidance
- from chart-specific claims to high-level pattern language
- from certainty to conditional phrasing
- from symbolic precision to practical reflection

## Birth Data Quality Levels

### Level 1: Exact birth date, time, and place

You can use all three layers with normal confidence, while still keeping symbolic claims bounded.

### Level 2: Birth date and place, but time is approximate

You can still use:

- scientific lens normally
- BaZi with caution around timing-sensitive nuance
- Western astrology with caution if rising sign or houses may shift
- Zi Wei Dou Shu only with clear mention that palace or star emphasis may be less stable

Recommended phrasing:

- `Because the birth time is approximate, the symbolic reading is more reliable at the theme level than at the fine-detail level.`

### Level 3: Birth date only

You can still use:

- scientific lens normally
- broad symbolic reflection with explicit limits

Reduce or avoid:

- house-specific Western astrology claims
- precise Zi Wei Dou Shu claims
- narrow timing claims

Recommended phrasing:

- `Without a reliable birth time, the symbolic systems are better used here as broad archetypal support rather than precise chart analysis.`

### Level 4: No birth data

Use the scientific layer as the clear primary method. If the user still wants symbolic content, offer only very light symbolic framing and state that it is not chart-based.

Recommended phrasing:

- `Since there is no birth data, I can still help through behavioral reasoning and use symbolic language only in a broad, non-chart-specific way.`

## Thin Narrative Data

If the user gives a very short prompt with almost no context:

- identify the probable core tension
- name two or three plausible interpretations
- ask for the one missing variable that would most improve the reading
- avoid sounding comprehensive when the input is not

## Contradictory Data

If the user gives conflicting facts:

- do not average them into false confidence
- name the contradiction directly
- show how the conclusion changes under each interpretation

Example:

- `If the main issue is burnout, the advice is to slow down before making a major move. If the main issue is underchallenge, the advice shifts toward expansion and experimentation.`

## High-Risk Topics

For topics involving:

- severe mental distress
- abuse
- self-harm
- medical uncertainty
- large financial exposure

Reduce symbolic emphasis and increase reality-based support. The skill should remain humane, but it must not use symbolism to overrule safety.
