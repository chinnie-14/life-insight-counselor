# Time And Evidence

Use this file when a consultation relies on birth time, chart precision, or any symbolic claim that should be made transparently.

## Purpose

This skill should not hide technical uncertainty behind confident language. When birth time, time standard, or chart method materially affects the reading, say so directly and explain what changes.

## Time Handling Rules

### Chinese symbolic systems

When using BaZi or Zi Wei Dou Shu, explicitly check:

- whether the user gave clock time or approximate time
- whether true solar time would materially change the result
- whether the case is near a day boundary or hour boundary
- whether different schools use different day-switch rules

If the result changes under different day-boundary rules, present:

- `version A`
- `version B`
- `shared conclusions across both versions`

Do not pretend there is a single certain chart when the method itself is disputed.

### Western astrology

When exact chart software is unavailable or precision is limited:

- distinguish clearly between date-stable placements and time-sensitive placements
- treat Sun, slow planets, and usually Moon sign as stronger support if the date is stable
- treat Ascendant, houses, MC, and some Moon changes as time-sensitive
- do not claim house-based or rising-sign conclusions unless the calculation is reliable

## Evidence Labels

Use transparent support labels when needed:

- `hard support`: directly grounded in the user's narrative or in stable chart data
- `moderate support`: plausible and supported by part of the symbolic structure, but not dependent on a single precise technical claim
- `light support`: thematic or symbolic resonance only

Example phrasing:

- `This part has hard support from your current job context and repeated pattern description.`
- `This part has moderate symbolic support because both candidate day-boundary methods point in the same direction.`
- `This part is only a light symbolic hint because the birth-time-sensitive components are not fully pinned down.`

## Transparent Reading Pattern

When a user asks what specifically supports the conclusion, answer in this order:

1. what is supported by the user's real-life facts
2. what is supported by Chinese symbolic structure
3. what is supported by Western chart structure
4. what remains uncertain

## Output Guidance

Use lines such as:

- `The main judgment does not depend on a fragile technical detail.`
- `Even under two chart methods, the practical conclusion remains the same.`
- `This symbolic layer supports the theme, but it is not the primary evidence.`
