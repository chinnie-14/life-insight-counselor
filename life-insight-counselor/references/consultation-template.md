# Consultation Template

Use this file when preparing the consultation inputs or shaping the final response.

## Consultation Modes

### 1. Life-path consultation

Use when the user wants broad guidance about:

- self-understanding
- career direction
- relationship patterns
- repeated struggles
- long-term life themes

### 2. Event-strategy consultation

Use when the user wants help with a specific short-term issue such as:

- whether to change jobs
- whether to start or continue a relationship
- whether to sign, delay, negotiate, or exit a partnership
- whether a move, launch, or transition is timely

## Input Checklist

### Core inputs for all consultations

- `question`: What does the user want help with, in one sentence if possible
- `goal`: What kind of answer do they want: clarity, decision support, timing, emotional insight, pattern diagnosis
- `life_stage`: Current age band, work state, relationship state, and major transition context
- `current_pressure`: What feels urgent, blocked, or emotionally charged right now
- `background_patterns`: Any repeating pattern in work, love, family, money, confidence, or self-sabotage

### Birth-data inputs for symbolic layers

- `birth_date`: Date of birth
- `birth_time`: Time of birth, including whether exact, approximate, or unknown
- `birth_place`: Birth city or region
- `calendar_note`: Anything relevant about lunar calendar conversion if already known by the user

### Extra inputs for event-strategy consultations

- `event_definition`: The exact decision or event being evaluated
- `time_window`: When it will happen or when the decision must be made
- `current_stage`: Still thinking, already started, negotiating, in conflict, near completion
- `desired_outcome`: What the user most wants from this situation
- `main_fear`: What the user most wants to avoid
- `constraints`: Money, family, health, geography, contract, energy, obligations, reputation
- `similar_history`: What happened in similar situations before

## Reasoning Priorities

Use this order when synthesizing:

1. Optional HUMAN 3.0 style development map when relevant
2. Scientific and behavioral interpretation
3. BaZi and Zi Wei Dou Shu pattern support
4. Western astrology pattern support
5. Overlap and contradiction mapping
6. Action translation

If symbolic systems point somewhere that the scientific layer does not support, state it as a symbolic theme rather than a factual judgment.

## Output Template

Use a structure close to this:

### 1. Core question

State the real problem beneath the user's surface question.

### 2. Scientific lens

Explain the main behavioral or psychological pattern. Prefer grounded reasoning about motivation, adaptation, habits, relational style, and risk profile.

### 3. Chinese symbolic lens

Summarize what BaZi and Zi Wei Dou Shu add. Focus on themes, structure, pressure, rhythm, and role tendencies rather than technical jargon unless the user asks for it.

### 4. Western symbolic lens

Summarize the natal-chart perspective. Focus on identity, emotional needs, relational dynamics, vocation, and growth tension.

### 5. High-confidence integrated insights

List the insights that recur across multiple systems. These carry the most weight.

### 6. Practical guidance

For life-path consultations, organize guidance into:

- `next 1-3 months`
- `next year`
- `long-term practice`

For event-strategy consultations, organize guidance into:

- `what favors action`
- `what favors waiting`
- `what to verify before deciding`
- `best next move`

## Optional Development Map Section

When the question involves identity transition, recurring stagnation, or multi-domain conflict, add a short section after `Core question` and before `Scientific lens`:

### Development map

- `surface domain`
- `root bottleneck domain`
- `current level tendency`
- `current phase`
- `knowledge / experience / skill gap`

## Optional Transparent Support Section

When the user asks `what exactly supports this conclusion` or when the chart precision is method-sensitive, add a short section near the end:

### Support breakdown

- `hard support from lived reality`
- `support from Chinese symbolic systems`
- `support from Western symbolic systems`
- `what remains uncertain`

## Tone Rules

- Be clear without sounding clinical.
- Be nuanced without becoming vague.
- Be respectful toward symbolic systems without overselling them.
- Name uncertainty whenever the data quality is weak.
- Avoid binary judgments about fate, worth, or permanent identity.
